# De Beste Repo Ooit

Een kleine website over de intermezzo's van het 5e jaar Hardware (richting ICW). Dit is een groepsopdracht voor Git en GitHub. We oefenen hoe je als team samenwerkt met branches, pull requests, code reviews, mergeconflicten en `.gitignore`.

## Inhoud van de website

- **Kevin Mitnick Games**: de hackingcontest van Oost-Vlaanderen, met de Wall of Fame
- **GitHub basisvaardigheden**: 8 interactieve lessen over Git en GitHub
- **Nokia Games**: telecom en thuisnetwerken, en een bezoek aan Nokia in Antwerpen
- **Snake**: een extraatje

## Structuur

| Map/bestand | Inhoud |
|---|---|
| `index.html` | Startpagina |
| `kevin-mitnick.html`, `github.html`, `nokia.html`, `snake.html` | Pagina's per onderwerp |
| `css/style.css` | Extern stylesheet |
| `js/` | Scripts (interactiviteit, snake) |
| `media/` | Afbeeldingen |
