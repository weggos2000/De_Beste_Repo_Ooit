Developer skills

GitHub basisvaardigheden

Git is het versiebeheersysteem dat zowat elke developer dagelijks gebruikt, en GitHub is het platform waarop miljoenen projecten erop draaien. In dit intermezzo doorlopen we acht interactieve lessen die je van nul naar zelfstandig gebruik brengen.

De 8 lessen

Klik een les open voor de uitleg, en vink aan wat je al hebt afgerond — je voortgang wordt onthouden op dit toestel.

Jouw voortgang 0/8 voltooid
  1. 1 Wat is Git, wat is GitHub?

    Het verschil tussen het versiebeheersysteem Git en het platform GitHub, en waarom developers ze gebruiken.

  2. 2 Een repository aanmaken

    Lokaal een repository initialiseren en koppelen aan een repository op GitHub.

  3. 3 Bestanden toevoegen en committen

    Werken met git add en git commit, en het schrijven van duidelijke commitberichten.

  4. 4 Wijzigingen pushen en pullen

    Lokale wijzigingen naar GitHub sturen en wijzigingen van anderen ophalen.

  5. 5 Werken met branches

    Een nieuwe branch aanmaken om aan een feature te werken zonder de hoofdcode te verstoren.

  6. 6 Merge conflicts oplossen

    Wat een mergeconflict is, hoe je het herkent en hoe je het manueel oplost.

  7. 7 Pull requests en code reviews

    Een pull request openen, feedback verwerken en code laten nakijken door een teamgenoot.

  8. 8 README en .gitignore

    Een project documenteren met een README en bepalen welke bestanden je niet wil versiebeheren.
