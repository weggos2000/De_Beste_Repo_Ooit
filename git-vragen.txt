19. Leg kort uit welk verschil jullie in de geschiedenis zien tussen een gewone merge en 'Squash and merge'.
Bij een gewone merge blijven alle commits van de branch apart in de geschiedenis staan en komt er
een extra merge commit bij met twee ouders ("Merge pull request #..."). In git log --graph zie je
daardoor de zijtak die terug samenkomt met main.
Bij 'Squash and merge' worden alle commits van een pull request samengeperst tot één nieuwe commit
op main met maar één ouder. De geschiedenis blijft dan een rechte lijn en de losse commits van de
branch zie je niet meer op main.
In onze repository zijn de pull requests met een gewone merge samengevoegd, daarom zie je in de
grafiek telkens de merge commits en de vertakkingen.
